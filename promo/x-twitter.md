1/ Give your AI agent a notebook that never forgets. 🧠📓
By default, assistants start each chat fresh. Wiki Memory turns conversations
into a searchable knowledge base the agent recalls later. → github.com/jonotonfoto/wiki-memory

2/ The trick: wiki + embeddings.
A wiki = readable, editable pages.
Embeddings = meaning-matching.
Together: the agent understands what you MEAN, not just what you say. 🤝

3/ Example: fix "printer prints blank pages" today → weeks later ask "why does
the copier print empty sheets?" → it finds the page. Synonyms don't break recall. ✨

4/ Cross-platform (Windows/Linux/Docker), pure Python + SQLite + numpy, no heavy
deps. Auto-indexes finished sessions. Optional holographic-memory bridge.

5/ Open source, MIT. Install: `hermes skills tap add jonotonfoto/wiki-memory`
